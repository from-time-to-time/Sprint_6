# Sprint 6

## О проекте
Репозиторий содержит UI-автотесты для учебного веб-сервиса «Яндекс.Самокат».
Тесты написаны на **Python 3 + Pytest + Selenium WebDriver** с применением паттерна **Page Object** и покрывают следующие пользовательские сценарии: <br>1) раскрытие выпадающих списков в разделе FAQ; <br>2) оформление заказа с двумя точками входа; <br>3) проверка работы логотипов «Самокат» и «Яндекс» в шапке сайта.

---

## Структура репозитория

```text
.
├── locators/                        # локаторы для разных страниц
│   ├── base_page_locators.py         # общие локаторы (cookie, лого)
│   ├── first_order_form_locators.py  # первая форма оформления заказа
│   ├── home_page_locators.py         # главная страница
│   └── second_order_form_locators.py # вторая форма оформления заказа
│
├── pages/                            # Page Object для страниц
│   ├── base_page.py                  # базовый класс со вспомогательными методами
│   ├── home_page.py                  # главная страница
│   └── order_page.py                 # страница оформления заказа
│
├── tests/                            # автотесты, сгруппированные по функционалу
│   ├── test_faq_form.py              # тесты выпадающего списка FAQ
│   ├── test_logo.py                  # тесты переходов по логотипам
│   └── test_order.py                 # тесты оформления заказа
│
├── config.py                         # глобальные настройки (URL, TIMEOUT)
├── conftest.py                       # фикстуры Pytest (инициализация драйвера и др.)
└── requirements.txt                  # зависимости проекта
```

## Описание тестов

### `tests/test_faq_form.py` — **TestFaqForm**
| Тест-кейс                                             | Что проверяет                                                                                            |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `test_faq_answer_text_is_correct` (параметризованный) | Для каждого вопроса в блоке «Вопросы о важном» при клике на стрелку открывается корректный текст ответа. |
---

### `tests/test_order.py` — **TestPositiveOrderFlow**
| Тест-кейс                                      | Что проверяет                                                                                                                                                                                                                                                                                                                                |
| ---------------------------------------------- |----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `test_order_positive_flow` (параметризованный) | Полный позитивный сценарий заказа самоката с двумя наборами тестовых данных: <br>1) вход в сценарий через верхнюю кнопку «Заказать» <br>2) вход в сценарий через нижнюю кнопку «Заказать». Включает: заполнение двух форм данными для заказа и проверку появления модального окна с сообщением об успешном создании заказа. |
---

### `tests/test_logo.py` — **TestLogosNavigation**
| Тест-кейс                                | Что проверяет                                                                             |
| ---------------------------------------- |-------------------------------------------------------------------------------------------|
| `test_logo_samokat_navigates_home`       | Клик по логотипу «Самокат» на странице заказа возвращает пользователя на главную страницу. |
| `test_logo_yandex_opens_dzen_in_new_tab` | Клик по логотипу «Яндекс» в шапке сайта открывает в новой вкладке страницу «Дзен».        |
